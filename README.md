# Flappy Bird Clone - Unity

Este é o meu **primeiro projeto** na área de **Desenvolvimento de Jogos**. O jogo foi criado como parte de um **tutorial do YouTube** do canal **Game Maker's Toolkit**, no qual recriei o clássico **Flappy Bird** utilizando **Unity**.

O objetivo deste projeto foi aprender conceitos básicos de **desenvolvimento de jogos 2D**, como **movimento de personagens**, **detecção de colisões**, e **controle de física simples** em Unity, além de ganhar mais experiência no uso da linguagem **C#**.

---

## 🔧 Tecnologias Utilizadas

- **Unity**: Engine utilizada para o desenvolvimento do jogo.
- **C#**: Linguagem de programação usada para implementar a lógica do jogo.
- **Assets 2D**: Gráficos e imagens utilizados para representar o personagem e os obstáculos.
